# Hi, I'm Anastasiia 👋

Robotics & Automation Engineer based in Finland.  
MSc in Automation Engineering (Robotics), Tampere University.

My background includes mobile robotics, control, simulation, computer vision, embedded systems, and hardware-software integration.

## Selected Projects

### Shared Human–AI Control for Unitree Go2
**Python · MuJoCo · Shared Autonomy · APF Navigation**

Team robotics project combining human teleoperation and autonomous navigation for a simulated Unitree Go2.

My main contributions:
- implemented the Artificial Potential Field (APF) controller;
- developed controller interfaces;
- created 2D and 3D real-time visualizations;
- contributed to system integration, testing, and debugging.

### Interpretable Dynamics Learning
**Python · PyTorch · MuJoCo · Gymnasium**

MSc thesis investigating Kolmogorov–Arnold Networks for learning robot dynamics and comparing them with standard MLP models.

Worked with Pendulum, Reacher, and HalfCheetah environments and evaluated prediction accuracy, generalization, long-horizon rollouts, and interpretability.

### FDM Defect Detection & Automated Print Monitoring
**Python · OpenCV · YOLOv5 · ESP32-CAM · OctoPrint**

Built an end-to-end prototype for detecting defects during FDM 3D printing.

The system combined computer vision with a physical printing setup and could automatically stop a failed print when significant defects were detected.

### Mobile Robot Localization, SLAM & Control
**EKF · EKF-SLAM · Obstacle Avoidance · Control**

Coursework at Tampere University covering wheel odometry, probabilistic localization, EKF localization and EKF-SLAM, obstacle avoidance, trajectory tracking, and waypoint navigation.
